Covellite.Api

Список классов проекта Api

Введение

Проект классов-оберток для графического API.

Подробнее

  • Классы проекта предоставляют реализации для различных графических API (OpenGL/OpenGLES3/DirectX).
  • Для каждого конкретного графического API создается отдельный класс.
  • Каждый класс доступен только для использования в коде для конкретной платформы.

Covellite.Api.Least

Вспомогательный проект, содержащий минимум включенных файлов, предназначенный для включения в тестовые проекты.
