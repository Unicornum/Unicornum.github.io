Подключение библиотек к решению

  • Скачать нужную версию Alicorn SDK и распаковать архив в папку (например) E:\SDK\Alicorn\vXXX.
  • Запустить install.cmd.
  • Файлы Directory.Build.targets и Externals.Error.props скопировать в корень решения (если нужно подключить только один проект, поместить файлы в папку этого проекта; также можно поместить их в любую папку в иерархии решения - SDK будет подключен ко всем проектам внутри этой папки).
Заметки
Externals.Error.props выводит сообщение об ошибке, если ожидаемая версия Alicorn SDK не найдена.

Описание классов решения

Для корректной сборки классов SDK необходимо включить раньше всех остальных файлов (например, в stdafx.h) файл

#include <alicorn/requirements.hpp>
